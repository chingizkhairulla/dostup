# Казахский перевод — на проверку носителю языка

**Что это.** 2026-10-15 было 195 мест (165 разных фраз), где казахский пользователь видел русский текст — в основном редактор продукта, материалы и объявления продавца. Казахский для них написан по словарю терминов, который уже используется в проекте (ниже). Носитель ещё не проверял: **мерж ждёт этой проверки.**

**Как проверять.** Колонка «Исправление» — пустая значит «верно». Если нужно иначе, впишите свой вариант. `{…}` — подставляемое значение (название файла, число), его не трогайте, только можно переставить в предложении.

**Как применить исправления** (для разработчика): перенести исправленные строки в `memory-bank/review/kk-translations.json` и выполнить
`node scripts/i18n-wrap.mjs memory-bank/review/kk-translations.json --kk --replace --write` — меняется только казахский слот, остальное скрипт не даст изменить.
