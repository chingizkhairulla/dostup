# Drag & Drop вложений в каналах и личных чатах

## Готовый промпт

Добавь загрузку файлов перетаскиванием (Drag & Drop) во все личные чаты и каналы раздела «Сообщения» для продавцов и покупателей, у которых есть право отправлять сообщения в выбранный диалог или канал.

Требования к интерфейсу:

1. Пользователь может перетащить один или несколько файлов в область открытого чата/канала.
2. Во время перетаскивания показывай заметную drop-зону с понятным текстом, например «Перетащите файлы сюда».
3. После отпускания файлов покажи список вложений до отправки: имя, тип, размер, прогресс загрузки и возможность удалить файл из черновика.
4. Существующая кнопка выбора файла должна продолжить работать; Drag & Drop является дополнительным способом загрузки.
5. Покажи понятные ошибки для неподдерживаемого формата, превышения размера, сетевого сбоя и отсутствия прав.
6. На устройствах без Drag & Drop интерфейс должен корректно работать через системный выбор файлов.

Функциональные требования:

- используй действующие в проекте ограничения на тип, размер и количество вложений; если единых ограничений ещё нет, вынеси их в общую конфигурацию для кнопки загрузки и Drag & Drop;
- не отправляй сообщение до успешной загрузки всех выбранных файлов либо явно показывай частично неуспешную загрузку с возможностью повторить;
- защити интерфейс от повторной отправки одного и того же вложения двойным событием drop/click;
- сохраняй исходное безопасное имя файла, MIME-тип и размер;
- проверяй тип и размер не только на клиенте, но и на сервере;
- файлы должны быть доступны только участникам личного чата или пользователям с доступом к каналу;
- Drag & Drop не должен обходить read-only режим, завершившийся доступ или права публикации в канале;
- корректно очищай незавершённые загрузки и временные объекты при отмене.

Критерии приёмки:

- продавец и покупатель могут перетащить файл в доступный им личный чат;
- пользователь с правом публикации может загрузить файл в канал;
- пользователь без права публикации не может загрузить файл ни через drop, ни через кнопку;
- несколько файлов отображаются с отдельным прогрессом и отправляются без дубликатов;
- ограничения и ошибки одинаковы для Drag & Drop и обычного выбора файлов;
- после обновления страницы отправленные вложения доступны адресатам согласно правам доступа.
