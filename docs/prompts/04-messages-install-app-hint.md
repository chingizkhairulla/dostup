# Одноразовая подсказка об установке приложения

## Готовый промпт

Добавь одноразовую подсказку при первом входе пользователя в раздел «Сообщения».

Текст подсказки:

**Скачайте приложение, чтобы получать уведомления!**

Правила показа:

1. Показывай подсказку всем авторизованным пользователям, кроме модераторов.
2. Показывай её только при первом входе конкретного профиля в раздел «Сообщения».
3. После закрытия больше не показывай её этому профилю, в том числе после выхода из аккаунта, очистки локального хранилища или входа с другого устройства.
4. Если у одного аккаунта несколько профилей, сохраняй состояние отдельно для каждого профиля.
5. Не показывай подсказку модератору даже при смене роли/профиля.
6. Подсказка не должна блокировать чтение сообщений и не должна появляться повторно при переключении между «Личными чатами», «Каналами» и «Неактивными».

Добавь в подсказку основное действие «Скачать приложение» или «Установить приложение», используя существующий сценарий установки PWA/приложения. Если установка уже выполнена или системный install prompt недоступен, не показывай неработающую кнопку: оставь краткую подсказку о включении уведомлений либо скрой карточку по действующим правилам продукта.

Храни признак показа на сервере в профиле пользователя или в отдельной таблице пользовательских подсказок. Запись должна быть идемпотентной и защищённой RLS.

Критерии приёмки:

- обычный пользователь видит подсказку один раз при первом входе в «Сообщения»;
- после закрытия она не появляется на другом устройстве;
- модератор не видит её никогда;
- смена вкладок внутри сообщений не вызывает повторный показ;
- действие установки использует существующий install flow и корректно обрабатывает неподдерживаемые платформы.
